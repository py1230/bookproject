# Book Project

一个基于 Next.js 的图书管理项目，具有以下功能：

## 功能特性

- 📚 图书浏览和管理
- 💬 实时聊天功能
- 📝 图书发布和编辑
- 👤 用户个人中心
- 🌙 深色/浅色主题切换
- 📱 响应式设计

## 技术栈

- **框架**: Next.js 16.2.0
- **UI 组件**: Radix UI + Tailwind CSS
- **样式**: Tailwind CSS
- **图标**: Lucide React
- **状态管理**: React Context
- **表单**: React Hook Form + Zod
- **部署**: GitHub Pages

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```
